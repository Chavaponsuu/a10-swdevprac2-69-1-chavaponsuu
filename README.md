## Getting Started

Install dependencies with `npm ci`. Copy `.env.example` to `.env.local`, then
replace `NEXTAUTH_SECRET` with a private value generated by
`openssl rand -base64 32`. Set `NEXTAUTH_URL` to your site's URL when deploying.
The local environment file is ignored by Git.

Assignment 10 uses NextAuth's credentials sign-in page at `/api/auth/signin`.
The navigation switches to `/api/auth/signout` after authentication. The
home banner greets the signed-in user, and `/booking` displays the user's
profile above the existing reservation form.

`BACKEND_API_URL` defaults to the assignment backend. If that service is busy,
set it to `https://a08-venue-explorer-backend-2.vercel.app/api/v1` or
`https://a08-venue-explorer-backend-3.vercel.app/api/v1` and restart the server.

Run the assignment checks with `npm test -- --runInBand`.

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
